# Code of conduct

## Participation

ZemDomu welcomes questions, bug reports, documentation improvements, and code
contributions from people with different backgrounds and levels of experience.

- Discuss the work and its evidence. Give specific, constructive feedback.
- Respect contributors' identities, boundaries, and differing experiences.
- Share only material you have permission to publish. Remove private source,
  credentials, and personal information from examples and screenshots.
- Avoid harassment, discrimination, threats, personal attacks, unwanted sexual
  attention, and publishing another person's private information.
- Keep issues, pull requests, and discussions relevant. Do not post spam or
  pressure contributors for unpaid work, reviews, or GitHub stars.

These expectations apply to this repository's issues, pull requests, discussions,
and other project spaces hosted on GitHub.

## Reporting a problem

Use GitHub's **Report content** menu on the relevant issue, discussion, or
comment. Where offered, choose **Report to repository admins** for project
moderation. You can also report platform abuse privately to GitHub Support
through [GitHub's reporting guidance](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

Include links and enough context to identify the behavior. Avoid repeating
private information or posting sensitive reports in a public issue.

## Moderation

Maintainers may remove disruptive content, explain the expected behavior, or
restrict participation using GitHub's moderation tools. The response should
reflect the severity, context, and any repeated behavior.
